# 设计文档更新摘要

## 更新日期
2024年（根据用户需求）

## 更新概述
根据用户提供的详细报价逻辑说明，对电气设备报价系统的设计文档进行了全面扩展和更新，整合了柜体分类体系、双模式报价、自动匹配规则、自动隐藏机制和人工费用联动计算等核心业务逻辑。

## 主要更新内容

### 1. 数据模型扩展

#### 1.1 Cabinets 表新增字段
- `control_category`：控制大类（低压类/配电类/控制类/自控类）
- `cabinet_type`：柜体类型（配电箱柜/控制箱柜/低压进线柜等）
- `control_structure`：控制结构（非标控制/自控型/纯PLC型/MCC柜/抽屉柜）
- `quotation_mode`：报价模式（detailed/quick）

#### 1.2 StructureComponents 表新增字段
- `circuit_type`：回路类型（电机回路/变频回路/三角降压等，用于非标柜）

#### 1.3 BaseComponents 表新增字段
- `component_category`：元器件分类（一次/二次/PLC/触摸屏/电源/端子等）
- `is_auto_matched`：是否为自动匹配的元器件
- `is_hidden`：是否被自动隐藏

#### 1.4 Materials 表新增字段
- `component_type`：元器件类型

#### 1.5 新增数据表
- **CabinetTypeConfigs**：柜体类型配置表，存储控制大类、柜体类型、控制结构的组合
- **AutoMatchRules**：自动匹配规则表，定义每种柜体配置应自动匹配的元器件
- **LaborCostRules**：人工费用规则表，定义不同柜体配置的人工费用计算规则

### 2. 柜体分类体系

建立了三级分类体系：
1. **控制大类**：低压类、配电类、控制类、自控类
2. **柜体类型**：配电箱/柜、控制箱/柜、低压进线柜/出线柜、低压补偿柜、低压控制柜
3. **控制结构**：非标控制、自控型、纯PLC型、MCC柜、抽屉柜

### 3. 双模式报价

#### 3.1 模式一：详细逐项报价（detailed）
- 适用场景：复杂或非标项目
- 完全手动控制，灵活度高
- 手动选择所有元器件

#### 3.2 模式二：快速报价（quick）
- 适用场景：标准或常规项目
- 系统自动匹配标准元器件
- 人工微调数量或补充特殊元件

### 4. 自动匹配规则

- 根据柜体配置（控制大类+柜体类型+控制结构）查询匹配规则
- 自动插入一次元器件、二次元器件、PLC及模块、触摸屏、电源、端子等
- 支持匹配优先级和默认数量配置

### 5. 自动隐藏机制

- 当控制结构为"非标控制"时，自动隐藏：
  - PLC及模块
  - 开关电源
  - 信号隔离器
  - 触摸屏
  - 编程调试费用
- 通过 `is_hidden` 字段实现，前端过滤显示

### 6. 人工费用联动计算

#### 6.1 费用构成
- 组装费 = 基础成本 × 组装费率
- 管理费 = 基础成本 × 管理费率
- 利润 = 基础成本 × 利润率
- 编程费（固定金额，仅当包含PLC）
- 调试费（固定金额，仅当包含PLC）

#### 6.2 联动触发时机
1. 创建配电柜时
2. 修改控制结构时
3. 添加/删除PLC元器件时
4. 元器件总价变化时

### 7. 非标柜报价原则

- 按回路拆分报价（电机回路、变频回路、三角降压回路等）
- 每个回路作为一个 StructureComponent
- 更灵活，避免漏项
- 支持保存回路模板

### 8. API 接口扩展

新增接口：
- `GET /api/cabinet-type-configs`：获取柜体类型配置列表
- `GET /api/cabinet-type-configs/{id}/auto-match-rules`：获取自动匹配规则
- `POST /api/cabinets/{id}/auto-match`：触发自动匹配
- `POST /api/cabinets/{id}/apply-hide-rules`：应用自动隐藏规则
- `POST /api/price-engine/calculate-labor`：计算人工费用
- `GET /api/materials/search?category=`：支持按分类过滤搜索

### 9. 后端服务扩展

新增服务模块：
- `auto_match_service.py`：自动匹配服务
- `labor_cost_service.py`：人工费用计算服务

新增数据模型：
- `cabinet_type_config.py`
- `auto_match_rule.py`
- `labor_cost_rule.py`

### 10. 前端组件扩展

新增组件：
- `CabinetTypeSelector`：柜体类型选择器
- `QuotationModeSelector`：报价模式选择器

新增 Composable：
- `useAutoMatch.ts`：自动匹配逻辑

新增 Store：
- `cabinetConfig.ts`：柜体配置状态管理

### 11. 正确性属性扩展

新增 6 个正确性属性（属性 20-25）：
- 属性 20：快速报价模式自动匹配完整性
- 属性 21：自动隐藏规则正确性
- 属性 22：人工费用计算正确性
- 属性 23：柜体类型配置唯一性
- 属性 24：报价模式一致性
- 属性 25：回路类型非标柜应用

### 12. 业务流程文档

新增详细的业务流程说明：
- 快速报价流程
- 详细报价流程
- 非标柜报价流程
- 人工费用联动触发时机

### 13. 错误处理扩展

新增错误处理策略：
- 柜体配置无效（422）
- 自动匹配规则缺失（422）
- 自动匹配错误处理逻辑
- 人工费用计算错误处理逻辑

### 14. 测试策略更新

新增测试覆盖模块：
- AutoMatchService
- LaborCostService
- CabinetTypeConfig
- AutoHideRules

新增属性测试示例：
- 自动匹配完整性测试
- 自动隐藏规则测试
- 人工费用计算测试

## 技术架构保持不变

- 前端：Vue 3 + Element Plus + Pinia
- 后端：Python Flask + SQLAlchemy
- 数据库：SQL Server
- 部署：Nginx + Waitress

## 向后兼容性

所有新增字段均设置了默认值或允许为空，确保与现有数据兼容。新增的业务逻辑为可选功能，不影响现有的基础报价流程。
